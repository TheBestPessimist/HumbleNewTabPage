As this is  an ongoing process, continue with the next batch of papercut fixes. Check the git commit and resume where you left off. (ie: if last commit's papercut was #51, then you continue with #52)

More hints:
- In the HumbleNewTabPage project, always run tests after making changes using the command: npm test

- Focus on performance:
